# موقع جمعية المبادرة المغربية للتكافل والتعاون لرعاية الأطفال في وضعية صعبة
## Association Initiative Marocaine pour la Solidarité et la Coopération (AMSED)

موقع إلكتروني رسمي متكامل، احترافي ومتعدد اللغات مخصص لجمعية رعاية الأطفال في وضعية صعبة بالمملكة المغربية.

---

### ✨ المميزات والخصائص المنجزة:

1. **دعم تعدد اللغات التلقائي واليدوي (Multilingual)**:
   - اللغات المدعومة: **العربية (العربية)**، **الفرنسية (Français)**، و**الإنجليزية (English)**.
   - **التبديل التلقائي الذكي**: يكتشف الموقع لغة متصفح الزائر تلقائياً (Automatic Browser Language Detection).
   - إمكانية التبديل اليدوي السلس في أي لحظة مع دعم كامل للاتجاهات (**RTL** للعربية و **LTR** للفرنسية والإنجليزية).
   - خطوط طباعية عربية متميزة (`Cairo`).

2. **الهوية البصرية والشعار الرسمي**:
   - إدماج الشعار الرسمي للجمعية المرفوع مع إطار ذهبي دائري ملكي وتأثيرات بصرية راقية.
   - إبراز شعار المملكة الخالد: **الله • الوطن • الملك**.

3. **قسم الإعلانات والمستجدات (Announcements)**:
   - تصنيف الإعلانات: (عاجل وهام، أنشطة وقوافل، بلاغات إخبارية).
   - بطاقات إخبارية مع صور وتواريخ ونافذة منبثقة لقراءة نص البلاغ كاملاً.

4. **قسم خدمات الجمعية (Services)**:
   - عرض متكامل للركائز الأساسية التي تقدمها الجمعية:
     1. الرعاية الصحية والقوافل الطبية للأطفال
     2. الدعم المدرسي ومحاربة الهدر والإنقاذ التعليمي
     3. الإيواء المؤقت والمساعدات الغذائية المستعجلة (قفة الخير)
     4. المواكبة والتأهيل النفسي ومركز الاستماع
     5. الأنشطة الترفيهية والمخيمات الصيفية والرياضة
     6. المواكبة القانونية والتسجيل بسجلات الحالة المدنية
   - إمكانية طلب مساعدة أو كفالة أي برنامج مباشرة.

5. **معرض الصور التفاعلي (Photo Gallery)**:
   - معرض صور عالي الجودة مقسم حسب الأنشطة (قوافل طبية، تعليم ودراسة، مساعدات اجتماعية، أنشطة وترفيه).
   - عارض صور مكبّر (Lightbox).

6. **قسم الفيديوهات اليومية والربط المباشر مع قناة يوتيوب (Daily Videos & YouTube)**:
   - مشغل فيديو مدمج لعرض "فيديو اليوم المميز".
   - زر مباشر للاشتراك في قناة يوتيوب.
   - خاصية المزامنة والتحديث التلقائي المباشر مع القناة.
   - أرشيف الفيديوهات اليومية والوثائقية لتدخلات الميدان.

7. **قسم التبرع والكفالة والتضامن (Donation & Solidarity)**:
   - برامج الكفالة: كفالة يتيم/مريض، دعم العمليات الجراحية، محفظة الأمل، قفة الخير.
   - الحساب البنكي الرسمي (RIB) مع زر النسخ السريع بنقرة واحدة.

8. **بيانات التواصل والمقر**:
   - الأرقام المعتمدة: **0663780107** و **0654240523**.
   - البريد الإلكتروني: **asso.amsed@gmail.com**.
   - زر المحادثة الفورية عبر واتساب (WhatsApp Direct).
   - روابط المنصات الرسمية: Facebook و YouTube.
   - نموذج اتصال ومراسلة تفاعلي يرسل الرسائل مباشرة إلى صندوق بريد لوحة تحكم الأدمن.

9. **لوحة تحكم الأدمن الشاملة (Admin CMS)**:
   - الدخول عبر أيقونة القفل في أعلى وأسفل الصفحة.
   - **كلمة المرور الافتراضية**: `admin123` (يمكن تغييرها من الإعدادات).
   - إدارة الإعلانات: إضافة، تعديل، حذف، تحديد الأولوية.
   - إدارة الخدمات: إضافة وتعديل وحذف برامج الجمعية.
   - إدارة معرض الصور: رفع وإضافة صور جديدة وتصنيفها.
   - إدارة الفيديوهات: إضافة فيديوهات جديدة، وتعيين فيديو اليوم، ومزامنة يوتيوب.
   - إدارة بيانات الاتصال: تعديل أرقام الهواتف، البريد، الروابط البنكية وصفحات التواصل.
   - صندوق الرسائل الواردة: قراءة رسائل الزوار وطلبات المساعدة والتطوع.
   - تصدير واسترجاع النسخ الاحتياطية (JSON Data Backup & Restore).

### 🚀 تشغيل المشروع محلياً:

```bash
# تثبيت الحزم
npm install

# تشغيل السيرفر المحلي
npm run dev

# بناء النسخة النهائية للنشر على الإنترنت
npm run build
```

الموقع يعمل حالياً على الرابط المحلي: **http://localhost:5173/**
